# Drone-Mobile-API
A Flask server for interacting with the (unofficial) Drone Mobile API.

I used this to create a Google/Alexa skill to start a vehicle or check on the status. By default, this script will work with one vehicle. However, all vehicles are loaded and the functions are built to easily support multiple (I just didn't have others to test with.) 

I ran this locally and whitelisted, so I have no form of "security" inside the script. If you are going to run this on a public server, I reccomend making those changes.
